Offline Imitation Learning

BC · MSE优势就是监督学习，简单稳定，不需要 reward。局限分布偏移会不断累积；MSE 可能把几种不同的动作平均成一个做不出来的动作。关键机制从专家状态—动作覆盖中学习。StrengthSimple supervised learning without rewards.LimitationCompounding error; MSE can average distinct action modes into an invalid action.Key mechanismLearn from expert state–action coverage.Probabilistic BC优势能表示随机的动作分布。局限单个 Gaussian 表示不了多峰。关键机制discrete / uncertain actions。StrengthRepresents stochastic actions.LimitationA single Gaussian still cannot represent multiple distinct modes.Key mechanismPredict a conditional action distribution.Diffusion / Flow优势能表示复杂、多峰的连续动作。局限一般要多步采样；只用示范训练时，本质仍是模仿学习。关键机制从 noise 生成 action chunk。StrengthExpresses complex multimodal continuous actions.LimitationOften needs iterative sampling; demonstration-only training remains imitation.Key mechanismGenerate an action chunk from noise.Action Chunking优势能保证动作在时间上连贯、平滑。局限开环执行太久会延迟反馈；预测多少步和执行多少步是两回事。关键机制执行前缀后重新观测与规划。StrengthModels temporal consistency and smooth action sequences.LimitationLong open-loop execution delays feedback; prediction and execution horizons differ.Key mechanismExecute a prefix, then observe and replan.

Interactive Imitation Learning

DAgger优势解决 BC 的 covariate shift。局限需要专家在线标注或接管。关键机制learner-visited states + expert relabel。StrengthAddresses behavior-cloning distribution shift.LimitationRequires expert labels or interventions on learner-visited states.Key mechanismAggregate learner states with expert relabeling.

On-Policy RL

REINFORCE优势直接优化期望回报。局限方差很大，样本效率低。关键机制log-derivative trick。StrengthDirectly optimizes expected return.LimitationHigh variance and costly fresh interaction.Key mechanismThe log-derivative policy-gradient estimator.Reward-to-Go / Baselines优势降低 Policy Gradient 的方差。局限如果 baseline 依赖采样到的动作，就会引入偏差。关键机制current action cannot affect past rewards。StrengthReduces policy-gradient variance.LimitationAn ordinary baseline depending on the sampled action can introduce bias.Key mechanismUse future rewards and action-independent baselines.Actor-Critic优势由 critic 估计 advantage，Policy Gradient 更高效。局限critic 估错了，会带来偏差和不稳定。关键机制actor + value/critic。StrengthUses a critic to improve gradient estimates and efficiency.LimitationCritic error can introduce bias or instability.Key mechanismAn actor paired with value/advantage estimation.PPO + GAE优势常用，容易扩展；clip 能抑制把 surrogate 推得过头的更新。局限每轮都要重新采样；clip 并不能严格保证 KL 不超限。关键机制Likelihood-ratio clipping 与 GAE 估计。StrengthWidely used; clipping discourages excessive surrogate improvement.LimitationNeeds fresh rollouts; clipping is not a hard KL guarantee.Key mechanismLikelihood-ratio clipping and GAE estimation.

Off-Policy RL

Q-Learning优势off-policy，不需要 actor。局限只在小的离散动作空间里好用，取 max 会高估。关键机制Bellman optimality。StrengthOff-policy learning without an explicit actor in small discrete spaces.LimitationAction maximization becomes difficult in large spaces and can overestimate values.Key mechanismA Bellman-optimality backup.DQN优势把 Q-learning 扩展到高维的 observation。局限主要适合离散动作，训练不太稳定。关键机制replay + target network。StrengthExtends Q-learning to high-dimensional observations.LimitationMainly discrete actions; approximation and bootstrapping can destabilize learning.Key mechanismReplay buffers and a target network.Double DQN / Clipped Q优势缓解高估。局限可能过于保守。关键机制select vs evaluate; min of two Qs。StrengthReduces overestimation.LimitationCan become conservative; the two mechanisms are distinct.Key mechanismDouble DQN separates selection/evaluation; clipped Q takes the minimum of critics.Off-Policy Actor-Critic优势样本效率高，适合连续控制。局限actor 会钻 Q 估计误差的空子。关键机制replay + critic target。StrengthReuses data efficiently for continuous control.LimitationThe actor can exploit critic errors.Key mechanismReplay, bootstrapped value targets and actor updates.SAC优势连续控制上样本效率高；entropy 项有助于探索。局限critic、temperature 和 replay 都不好调。关键机制max reward + entropy; twin Q。StrengthSample-efficient continuous control with entropy-driven exploration.LimitationSensitive to critic quality, entropy temperature and replay.Key mechanismReward plus entropy with twin Q functions.

Offline RL

Filtered BC优势简单、常用的强基线。局限丢弃部分数据，也不显式学习基于价值的轨迹拼接。关键机制模仿高回报轨迹。StrengthA simple, often strong baseline.LimitationDiscards data and does not explicitly learn value-based trajectory stitching.Key mechanismImitate high-return trajectories.AWR优势按 advantage 加权的模仿，不会直接选数据外的动作。局限用 Monte Carlo 估 advantage，方差大。关键机制weighted log-likelihood。StrengthAdvantage-weighted imitation without explicitly choosing unseen actions.LimitationMonte Carlo advantage estimates can have high variance.Key mechanismWeighted action log-likelihood.AWAC优势用 TD critic 估计 advantage，信号更强。局限计算 critic target 时仍可能查询数据外的动作。关键机制offline-to-online style。StrengthUses TD values for advantage-weighted improvement.LimitationCritic backups can still query unsupported actions.Key mechanismAdvantage-weighted updates for offline-to-online learning.IQL优势不显式查询数据外的动作，还能拼接不同轨迹的片段。局限依赖数据的覆盖范围，对 expectile 和 temperature 敏感。关键机制upper expectile V + weighted BC。StrengthAvoids explicit out-of-data action queries in value updates and supports stitching.LimitationLimited by dataset support and expectile/temperature choices.Key mechanismUpper-expectile value learning plus weighted behavior cloning.

Estimation & Update Control

MC / TD / N-Step优势在完整回报与更及时的 bootstrap 反馈之间选择。局限MC 方差大；TD 依赖价值估计准不准；off-policy 的 n-step 需要校正。关键机制改变 backup horizon 与 bootstrap 项。StrengthTrades full-return estimates against earlier bootstrapped feedback.LimitationMonte Carlo has high variance; TD depends on value accuracy; off-policy n-step targets need care.Key mechanismChange the backup horizon and bootstrap term.Importance Sampling / KL优势支持数据复用，并控制策略更新幅度。局限importance ratio 的方差可能很大；clip 会引入偏差。关键机制Importance ratio 校正分布；KL 约束变化。StrengthSupports data reuse and controls policy-update size.LimitationImportance weights can have extreme variance; clipping introduces bias.Key mechanismImportance ratios correct distributions; KL constrains change.Expectile Regression优势让 IQL 在数据覆盖范围内偏向高价值的动作。局限expectile 取得太高会过于乐观。关键机制asymmetric squared loss。StrengthFavors higher supported values in IQL.LimitationExtreme expectiles can be overly optimistic.Key mechanismAsymmetric squared-error regression.

Model-Based RL & Planning

MPC / Planning优势能往前看几步；每步重新规划，可以纠正模型误差。局限规划得越远，模型误差累积越多。关键机制execute first action only。StrengthLooks ahead and replans using new observations.LimitationModel error and optimization cost grow with horizon.Key mechanismExecute the beginning of a newly optimized plan.Dyna / MBPO优势用模型生成的 rollout 提高样本效率。局限模型偏差会污染 critic 和 policy。关键机制short rollouts from real replay states。StrengthUses synthetic experience to improve sample efficiency.LimitationModel bias can contaminate the policy and critic.Key mechanismShort model rollouts from replay-buffer states.

Reward & Preference Learning

Reward / Goal Classifier优势比手写 reward 省事。局限分类器的盲区会被策略钻空子。关键机制need on-policy negatives。StrengthCan be easier to specify than a hand-designed dense reward.LimitationPolicies can exploit classifier blind spots.Key mechanismInclude negatives from the policy’s actual behavior.Preference Reward Model优势两两比较比打绝对分数容易。局限reward model 会被 policy 钻空子。关键机制Bradley-Terry likelihood。StrengthPairwise comparisons may be easier than absolute scoring.LimitationPolicies can exploit reward-model errors.Key mechanismBradley–Terry preference likelihood.RLHF优势能优化那些说不清、但人能判断的偏好。局限流程复杂，KL 和 reward 之间的平衡很敏感。关键机制SFT -> RM -> PPO + KL。StrengthOptimizes behavior from learned human preferences.LimitationA complex pipeline with sensitive reward/KL balance.Key mechanismA common recipe: SFT, reward modeling, then PPO with KL regularization.DPO优势不用单独训练 reward model，也不用跑 online RL。局限效果取决于离线偏好数据覆盖得全不全。关键机制direct preference objective。StrengthNo separate reward-model training or online RL loop.LimitationDepends on offline preference coverage.Key mechanismDirect optimization of a preference objective.

Multi-Task RL & Inference

Multi-Task RL优势共享参数，提高数据效率。局限任务差别太大时会出现 negative transfer。关键机制policy/Q condition on task id。StrengthShares parameters and experience across tasks.LimitationDifferent tasks can interfere and cause negative transfer.Key mechanismCondition both policy and critic on the task.GCRL / HER优势把没完成原目标的轨迹，重新标成“完成了实际到达的那个目标”，变成有用的经验。局限必须能针对新目标重新计算 reward 和终止条件。关键机制Hindsight goal relabeling。StrengthRelabels failures as useful experience for achieved goals.LimitationRewards and termination must be recomputable for the relabeled goal.Key mechanismHindsight goal relabeling.Test-Time Compute优势用更多推理算力换性能。局限延迟和成本都会上升。关键机制CoT, best-of-N, consensus, search。StrengthTrades additional inference compute for better decisions.LimitationHigher latency and compute cost.Key mechanismReasoning, best-of-N, consensus or search.

看一个算法，先问四个问题：训练时还能不能继续采数据？监督信号来自动作、回报还是偏好？更新时会不会查询数据之外的动作？部署时要不要用模型或做规划？Action chunking、GAE 和 replay buffer 是可以搭配使用的部件，和 PPO、IQL 不在一个层级上，不能拿来互相替代。

First ask whether new data can be collected, what provides supervision, whether updates query out-of-data actions, and whether deployment needs a model or planner. Chunking, GAE and replay are composable components, not alternatives at the same level as PPO or IQL.

2MDP、数据分布与目标MDPs, data distributions and objectives

MDP 用状态 s、动作 a、转移 、奖励 r 和折扣 γ 来定义问题。但机器人从相机拿到的只是 observation o，一帧图像往往看不出速度、被挡住的东西和接触状态。所以策略需要借助历史、递归状态或状态估计，尽量补全做决策需要的信息。

An MDP specifies states, actions, transitions, rewards and a discount. A robot camera supplies observations: one image may omit velocity, occluded objects or contact. History, recurrent state or state estimation helps retain information needed for decisions.

维度Dimension定义与例子Definition and example
Online / Offline训练时是否还继续和环境交互。用固定数据训练 IQL 是 offline；边训练边采数据的 SAC 是 online。Whether training collects new experience. Fixed-data IQL is offline; SAC with continued collection is online.
On-policy / Off-policy更新时用的是谁采的数据。PPO 只用当前这一轮策略采的数据；SAC 可以复用以前旧策略采的数据。Which distribution an update requires. PPO uses its current rollout batch; SAC reuses earlier behavior-policy data.
Model-free / Model-based是否学习或使用一个转移模型，用来规划或生成训练经验。注意 critic 不是动力学模型。Whether transition models support planning or synthetic experience; a critic is not a dynamics model.

看起来等价的奖励改动，可能悄悄改变了任务。把奖励乘一个正数，原来期望回报的最优解不变，但熵系数这类固定正则项的相对分量变了；每一步加一个常数，只有在所有策略的回合长度都一样时才不影响偏好，如果任务可以提前结束，这个“生存奖励”就会鼓励策略拖时间。改 γ 或对 reward 做非线性变换，一般也会改变优化目标。

Seemingly equivalent rewards can change the problem. Positive scaling preserves optimal policies for the unregularized return, but changes the relative strength of a fixed entropy penalty. Adding a per-step constant is neutral only when discounted horizons are policy-independent; with controllable termination it can reward delay. Changing γ or applying nonlinear reward transforms can also change preferences.

3Imitation Learning：分布、误差与反馈Imitation: distributions, errors and feedback

BC 在学什么，MSE 为什么会出问题What BC learns, and why MSE can fail

BC 用专家的动作做监督，不需要奖励。可如果从左边、右边绕过障碍物都行，MSE 可能会输出两条路线的平均，正好撞上障碍物。网络再大也没用，因为平方误差学到的就是条件均值；要么换一个能表示多峰的分布，要么给足条件信息，让模型知道该走哪边。

BC uses expert actions without requiring rewards. When either side of an obstacle works, MSE may predict an average that collides. A larger network does not change squared error’s conditional-mean target. Use an expressive distribution or conditions that resolve the ambiguity.

生成式动作模型与 action chunkGenerative policies and action chunks

Diffusion 和 Flow Matching 用“从噪声生成动作”的过程来表示复杂分布；ACT 则借助 CVAE 训练 action chunk。它们都可以拿来做模仿学习，之后也都可以再用 RL 改进。“用了 diffusion”只说明了策略怎么表示，并没有说明训练的反馈从哪来 [1, 2, 58]。

Diffusion and flow matching represent rich action distributions through noise-to-action generation; ACT uses CVAE training for chunks. These representations can serve imitation or later RL. “Diffusion” describes the policy representation, not the source of learning feedback [1, 2, 58].

预测长度不等于开环执行长度Prediction horizon differs from execution horizon

每次预测 H 步，只执行前 K 步，再看一眼新的图像，这就是 receding-horizon 控制。chunk 长一些，动作更连贯；K 小一些，反馈的机会更多。但观测过时和推理耗时，仍然会拖慢闭环。ACT 的 temporal ensembling 融合的是多个 chunk 对同一时刻的预测，不是随便把相邻时刻的动作平均一下。

Predict H steps, execute the first K, then observe again. Longer chunks model temporal structure; shorter execution prefixes preserve feedback. Stale observations and inference time still limit responsiveness. ACT temporal ensembling combines predictions for the same execution time, not arbitrary adjacent actions.

DAgger：修正训练分布DAgger: repair the training distribution

BC 是在专家走过的状态上训练的，部署时机器人却走在自己的状态上。DAgger 的做法是：先让当前策略跑一遍，再请专家标注这些状态下该怎么做，把它们加进训练集重新学 [90]。关键在于“学生走到的状态 + 专家给的动作”。如果把自己失败时的动作也加进 BC，只会强化错误；专家能不能及时接管、有没有覆盖恢复过程，也决定了这些数据有多大价值。

BC trains on expert states but visits its own states at deployment. DAgger rolls out the current learner, asks an expert for actions at those states, aggregates the labels and retrains [90]. Adding the learner’s failed actions as BC targets can reinforce mistakes. Timely intervention and recovery coverage determine correction value.

4Policy Gradient 与估计器Policy gradients and estimators

从轨迹概率到 REINFORCEFrom trajectory probabilities to REINFORCE

环境的转移和 θ 无关，所以对轨迹 log-prob 求梯度，只剩下策略那一项。回报高于基线，就提高对应动作的概率；低于基线，就降低。当前动作影响不了过去的奖励，所以用 reward-to-go 可以去掉这部分无关的噪声。基线可以依赖状态，但一般不能依赖当前采样的动作；给 actor 用的回报或优势通常要 stop-gradient，别把 critic 的梯度也当成这个估计器的一部分。

When environment dynamics do not depend on θ, only policy factors remain in the trajectory log-gradient. Returns above baseline increase action probability. Reward-to-go removes past rewards that the current action cannot affect. Ordinary baselines must be independent of the sampled action. Stop gradients through the return or advantage used by this actor estimator.

MC、TD、n-step 与 GAEMC, TD, n-step and GAE

估计器Estimator目标Target主要权衡Main costs and limitations
Monte Carlo用完整的同策略回报，不依赖 bootstrap；但方差大，而且要等到回合结束。Complete on-policy returns avoid bootstrap error; variance and waiting cost can be high.
TD(0)更新更及时，但会带进当前 V 的误差。Immediate updates, but inherits errors in V.
n-step在回报噪声和 bootstrap 误差之间折中。Trades return noise against bootstrap error.
GAEλ 调的是 TD residual 往后看多远，和探索强度无关。λ controls the horizon of TD residuals, not exploration strength.

d 表示回合真正结束。如果只是因为到了采样的时间上限被截断，未来价值不一定该清零，要看任务怎么定义。Off-policy 的长 n-step 回报里混进了行为策略后面的动作，也不能不加处理就当成当前策略的回报。Actor-Critic 借这些估计器降低方差，代价是更依赖 critic 的质量。

Here d marks genuine termination. A collection time limit does not always justify zeroing future value; use the task’s termination semantics. Long off-policy returns contain behavior-policy actions and cannot automatically be treated as current-policy returns. Actor-critic methods reduce variance while increasing dependence on critic quality.

Importance ratio：复用旧数据的代价Importance ratios: the cost of data reuse

用旧策略 μ 的数据估计新策略 π，常出现 这个比值。前提是旧策略要覆盖到新策略会做的动作；如果要校正整条轨迹，还得把每一步的比值乘起来，方差可能大到失控。PPO 里逐步的 ratio 只是局部 surrogate 的一部分，并不能把任意的旧 replay 变成无偏的 on-policy 数据。

Reusing behavior-policy μ data for π introduces likelihood ratios and requires support coverage. Full trajectory correction involves products across time and can have extreme variance. PPO’s stepwise ratio belongs to a local surrogate; it does not make arbitrary replay data unbiased on-policy samples.

5PPO、SAC 与 Q-learningPPO, SAC and Q-learning

PPO：一批新数据反复用几轮PPO: bounded reuse of fresh data

PPO 最大化下面这个 clipped surrogate（这里只写了 actor 的目标）。

PPO maximizes the clipped surrogate below; this is the actor objective.

先用 采 rollout，算出 value target 和 GAE，在这批数据上更新几轮，然后重新采样 [87]。Clip 的作用是让“把 surrogate 推得过头”的更新得不到好处，但它并没有严格限制每个状态的 ratio 或 KL，所以训练时还是要盯着 KL、clip fraction、value loss 和实际回报。仿真里采样快，PPO 很好用；真机交互宝贵时，就要仔细算算每次更新到底用了多少新数据。

Collect rollouts with , compute value targets and GAE, run a bounded number of updates, then recollect [87]. Clipping removes incentives for excessive surrogate improvements; it does not impose a hard global ratio or KL bound. Monitor KL, clip fraction, value loss and return. High-throughput simulation suits this loop; scarce real interaction makes its fresh-data cost significant.

SAC：靠 replay 提高样本效率SAC: reuse replay for sample efficiency

SAC 把新的 transition 存进 replay，更新两个 Q 网络、actor 和缓慢跟随的 target network，熵温度 α 也可以学 [88]。Actor 不只追求高 Q 值，还要保持策略的熵。它能把昂贵的真机数据反复利用，但也会钻 critic 的盲区；提高 UTD（每次交互后做更多次梯度更新）可能更充分地利用数据，也可能在同一批误差上过拟合。熵有助于探索，但不保证能碰到稀疏的成功事件。

SAC alternates collection with replay-based twin-Q and actor updates, slow target updates and optionally temperature learning [88]. Entropy complements value maximization. Reuse helps expensive real-robot data, but the actor can exploit critic blind spots. Higher update-to-data ratios may improve efficiency or overfit errors; entropy alone does not solve sparse exploration.

Q-learning 与 DQNQ-learning and DQN

Q-learning 用 Bellman 最优方程做备份，学习动作价值。DQN 用神经网络来近似 Q，用 replay 打散数据之间的相关性，再用 target network 缓解目标不断变化带来的不稳定。动作少且离散时，直接枚举取 max 很自然；连续的高维动作没法枚举，就要靠 actor 来近似求最大值。

Q-learning uses Bellman optimality backups. DQN adds neural approximation, replay and target networks. Enumerating the maximizing action works naturally for small discrete spaces; high-dimensional continuous actions require optimization machinery such as an actor.

Double DQN 不等于 Clipped Double QDouble DQN differs from clipped double Q

Double DQN 用在线网络选出 argmax，再用目标网络去评价这个动作，避免“同一份噪声既用来选又用来评，于是被高估”。SAC 常用的 clipped double Q，是在两个 critic 里取较小的那个。两者目的相近，但公式和数据流都不同；取最小值也可能让估计过于保守。

Double DQN selects an action with the online network and evaluates it with the target network. Clipped double Q takes the minimum of two critics, as commonly used in SAC. Both address overestimation but are different mechanisms; the minimum can be overly pessimistic.

6Offline RL：数据外的动作与轨迹拼接Offline RL: unseen actions and stitching

在线 RL 可以靠新的交互纠正 critic，离线 RL 没有这个机会。策略一旦偏向数据之外、Q 值又被高估的动作，这个错误就会通过 Bellman backup 一遍遍放大。这是数据覆盖范围的问题，在 replay 上训练得再久也解决不了。

Online interaction can correct critic errors; fixed-data training cannot. A policy that selects unsupported high-Q actions can amplify errors through Bellman backups. This is a support problem, not something solved by training longer.

IQL：分三步看IQL in three updates

第一步，对数据里动作的 Q 做不对称的平方误差回归，得到一个偏向较好动作的 V；第二步，用 往回传价值；第三步，最大化按优势加权的 log-likelihood，提取出策略 [89]。Expectile 不是 quantile，也不是直接取最大值。实现时 target 要 stop-gradient，权重通常要截断，免得数值爆掉。另外，部署时的策略仍可能因为泛化误差输出数据外的动作：训练时只用数据内的样本更新，不等于执行时就一定安全。

First fit an upper expectile of dataset-action Q values, then back up , then maximize advantage-weighted log-likelihood to extract a policy [89]. Expectiles are neither quantiles nor literal maxima. Stop gradients through targets and control extreme weights. In-sample training updates do not guarantee that the deployed function approximator never produces unsupported actions.

举个 stitching 的例子：数据里有一条从 A 到 B 的好路径，也有一条从 B 到 C 的好路径，但没有一条从 A 走到 C 的完整成功轨迹。只要中间状态 B 表示得好、附近的转移覆盖得够，价值就能从 C 一路传回 A。如果 B 附近没有能执行的衔接，或者观测把不同的接触状态混在了一起，就拼不出一个可靠的策略。

Suppose data contains useful A→B and B→C segments but no successful A→C trajectory. With compatible state representations and transition coverage, values can propagate from C back to A. Missing executable transitions or observations that alias different contact states can defeat this stitching.

7Reward Learning、RLHF 与 DPOReward learning, RLHF and DPO

奖励模型在分布外也会出错Reward models also fail out of distribution

用成功/失败分类器把图像变成奖励，机器人可能学会挡住摄像头，或者摆出一个“看起来像成功”的姿势。要分清三个数：分类器的训练准确率、策略优化后拿到的奖励分数，以及真实的任务完成率。多收集当前策略的失败样本，能发现原始数据里没有的盲区。

A success classifier turns images into rewards, but optimization can find success-looking failures. Distinguish classifier accuracy, optimized reward scores and true completion. Failures from the current policy reveal blind spots absent from the original dataset.

RLHF：先学奖励，再优化策略RLHF: learn a reward, then optimize a policy

常见的流程是：SFT → 收集偏好 → 拟合 reward model → 在参考策略约束下做 RL。KL 约束让策略不会太快跑出奖励模型可信的区域，但它并不能保证结果正确。在机器人里，人工纠正、成功判别器和偏好反馈提供的信息各不相同，不应该都笼统地叫 RLHF。

A common pipeline is SFT, preference collection, reward-model fitting, and RL with a reference-policy constraint. KL regularization limits rapid drift but does not prove reward correctness. Robot corrections, success classifiers and preference comparisons provide different signals.

DPO：直接优化偏好目标DPO: optimize preferences directly

DPO 把一类带 KL 正则的偏好优化问题，改写成一个直接的分类损失，不用单独训练奖励模型，这一步也不用跑在线 RL [93]。它更简洁，但固定的偏好数据不会自己去探索新行为。要把它搬到连续的 action chunk 上，还得解决轨迹概率怎么算、动作分布怎么表示、反馈粒度怎么定这些问题。

Original DPO rewrites a particular KL-regularized preference problem as a direct classification loss, without an explicit reward model or online RL in that optimization stage [93]. Fixed preferences do not explore new behaviors. Continuous action chunks additionally require tractable probabilities and an appropriate feedback unit.

8Model-Based RL：在线规划与用模型生成经验Model-based RL: online planning and model-generated experience

MPC 每次只执行计划的第一步MPC executes only the start of its plan

有了转移模型，就可以采样或优化一串动作，预测未来的收益，只执行第一个动作，然后根据新的观测重新规划。MPC 的闭环来自这种不断的重新规划，和贪心地选即时 reward 最大的动作不是一回事。规划得越远，看得越长远，但模型误差也累积得越多；规划范围之外的部分，可以用 terminal value 来估计。

A learned transition model can score candidate action sequences. Execute the first action and replan with a fresh observation. Longer horizons add lookahead but accumulate model error; a terminal value estimates benefits beyond the planning window. Greedy immediate-reward selection is not equivalent.

Dyna / MBPO：部署时不一定需要模型Dyna / MBPO: a model can be used only in training

短 rollout、模型 ensemble 和限制策略偏移，都能缓解 model bias；但 ensemble 里的模型意见一致，也可能只是大家有同一个盲区。和测试时用 World Model 做规划不同，Dyna 式的方法可以只在训练时用模型，最后部署的是一个普通策略。

Short rollouts, ensembles and controlled policy shifts can limit model bias, although an ensemble may share blind spots. Unlike test-time planning, Dyna-style learning can use the model only in training and deploy an ordinary policy.

9Multi-Task、Goal-Conditioned 与 HERMulti-task, goal-conditioned RL and HER

任务条件要同时输入 policy 和 criticCondition both policy and critic on the task

多任务 RL 用 、 把任务作为条件输入。共享参数能复用技能，但任务之间梯度冲突、样本数量不均衡时，也会出现 negative transfer。不同任务可能连 reward、初始状态，甚至 dynamics 和 action space 都不一样，不能默认它们只差一个目标 token。

Multi-task RL conditions both policies and critics on task identity z. Shared parameters can transfer skills, but gradient conflict and uneven sampling can cause negative transfer. Tasks may change rewards, initial states, dynamics or action spaces, not just a goal token.

HER：重新标注目标，复用经验HER: goal relabeling and experience reuse

Goal-conditioned RL 把目标 g 作为条件输入。HER 把一条没达成原目标的轨迹，按它实际到达的 g′ 重新算奖励，当作另一个任务的经验来用 [91]。前提是奖励能按新目标重算，而且换目标不会改变这段转移的动力学；通常和 off-policy 的 replay 一起用。机器人没把东西放进 A，却放进了 B，这条经验能帮它学“放进 B”，但不能说明它已经会“放进 A”了。

Goal-conditioned RL adds goal g to the policy. HER recomputes rewards using an achieved g′ and reuses the transition for that goal [91]. Rewards must be recomputable and the goal must not invalidate the transition dynamics. Reaching bin B while aiming for A teaches something about B, not proof of competence at A.

在有随机性的环境里，事后再挑目标还会带来偏差；“失败都能变成成功”并不是无条件成立的。对于用语言描述的任务，哪些目标可以等价地重新标注，也需要先把任务的含义说清楚。

In stochastic environments, hindsight goal selection can introduce bias. Relabeling is not an unconditional theorem that every failure becomes useful success. Language tasks additionally need a well-defined meaning for the substituted goal.

多花推理算力，不等于多了学习反馈Inference compute is distinct from learning feedback

CoT、best-of-N、consensus 和 search 都是在测试时多花算力。它们能不能让机器人表现更好，取决于候选怎么生成、用什么验证、执行时延能不能接受；会推理任务步骤，不等于能给出稳定的电机指令。GRPO 这类方法用同一组样本之间的相对回报构造学习信号，是训练算法，和测试时多采样几次不是一回事。

CoT, best-of-N, consensus and search spend more inference compute. Their value for robotics depends on candidates, verification and latency. Reasoning about a task does not itself produce stable motor control. Group-relative policy optimization uses relative rewards as a training signal, distinct from sampling more candidates at test time.

For example, SGS changes which states simulation RL visits; HIL-SERL changes the real-robot interaction and correction loop; π*0.6 connects values and deployment feedback to pretrained policies. Locate the changed component first, then inspect evidence for the claimed benefit.
