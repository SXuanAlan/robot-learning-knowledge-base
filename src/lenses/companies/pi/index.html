Physical Intelligence

π 系列的主线，是把网络上的语义知识、机器人动作与执行后的反馈接起来。版本号背后有不同的问题：动作怎样表示、跨场景知识怎样迁移、失败怎样变成训练信号，以及大模型怎样实时控制。

The π series connects web knowledge, robot actions and feedback from execution. Its reports address distinct problems: action representation, transfer across scenes, learning from failures, and real-time control with large models.

这些工作不能简单理解为同一个模型不断变大。FAST 改动作编码，RTC 改推理时的执行，RLT 改在线优化接口；它们的实验对象和训练阶段不同。把名称按技术问题归位，才能判断一种改进是否能迁移到自己的系统。

These are not just larger checkpoints of one model. FAST changes the action representation, RTC changes execution at inference, and RLT changes the online-learning interface. Their experiments concern different stages; that distinction determines whether an idea transfers to another robot.

2从语言骨干到连续动作From a language backbone to continuous actions

π0 用预训练 VLM 理解图像和指令，再让动作专家通过 flow matching 生成连续动作块 [5]。动作块让模型一次给出一段轨迹，也把时延问题暴露出来：模型下一次看见现场之前，这段轨迹是否仍然有效？

π0 combines a pretrained VLM with an action expert that generates continuous action chunks through flow matching [5]. Chunking predicts a short trajectory at once. It also creates a control question: will that trajectory remain appropriate before the model next observes the scene?

FAST 对动作序列做 DCT 压缩，再用 BPE 编成 token；它解决逐时刻、逐关节离散化带来的冗余 [45]。KI 则让 FAST 动作监督训练骨干，同时阻断连续动作专家向骨干回传的梯度，部署时仍由连续专家输出动作 [46]。这里的重点是优化路径：语义表征需要适应机器人，但新接入的动作模块不应把它破坏。

FAST compresses temporal actions using DCT and BPE, reducing the redundancy of per-joint, per-timestep tokens [45]. KI trains the backbone with FAST supervision while stopping gradients from the continuous expert into it; deployment uses continuous actions [46]. The underlying issue is optimization: robot adaptation must preserve useful semantic representations.

3π0.5：数据混合如何服务泛化π0.5: what heterogeneous data contributes

π0.5 将机器人动作、视觉语言任务和高层语义标注联合训练，研究在未见家庭里执行整理任务 [44]。这些数据不是可互换的小时数：动作示范约束“怎么动”，语义数据帮助判断“下一步做什么”，多本体数据则扩展技能覆盖。应看消融中是哪一种知识迁移，而不只看总数据量。

π0.5 co-trains robot actions, vision-language tasks and high-level semantic labels for household generalization [44]. These sources are not interchangeable hours: actions constrain movement, semantics support subtask selection, and multiple bodies broaden experience. Ablations should reveal which knowledge transfers, beyond reporting dataset size.

后续的人类视频研究观察到：随着机器人数据规模增大，VLA 利用人的示范的能力也会增强 [36]。这给“人类数据替代机器人数据”的叙事加了一个条件——两者可能互相解锁。可以把机器人数据理解为对齐动作含义的锚点，再问人类数据增加了哪些此前没有的技能与场景。

Later human-video experiments find that transfer improves with robot-data scale [36]. Human and robot data may therefore unlock one another. Robot experience can anchor action meaning, while human data broadens coverage; the useful question is which new skills and scenes the mixture actually adds.

4π*0.6 与 RLT：两种反馈学习π*0.6 and RLT: two feedback-learning interfaces

RECAP 学习价值函数，用状态价值的变化估计动作优势，再训练 advantage-conditioned 策略；执行时条件化到较高优势。π*0.6 结合离线数据、机器人自主尝试与专家纠正 [11]。它让失败也提供信息，但价值估计误差会进入策略更新，因此不能把“有奖励反馈”直接等同于可靠的自我改进。

RECAP learns a value function, estimates action advantages, and trains an advantage-conditioned policy, requesting favorable actions at execution. π*0.6 combines offline data, autonomous attempts and expert corrections [11]. Failures become informative, but errors in value estimation can also shape policy learning.

RLT 针对“最后几毫米”：从 VLA 提取紧凑 RL token，供轻量策略在线学习，而非在线更新整套大模型 [49]。这与 RECAP 的广泛行为改进互补。比较时要问：调整的是整个任务策略还是局部精细控制？试错时间、重置成本和最终吞吐量各是多少？

RLT targets precise manipulation by exposing a compact RL token to a lightweight online learner instead of updating the entire VLA [49]. It complements RECAP’s broader improvement loop. Compare the scope of adaptation, robot interaction time, reset cost and final throughput.

5记忆、实时执行与 π0.7Memory, real-time execution and π0.7

MEM 用短期视觉历史保留近期细节，用自然语言概念存储长期进度 [47]。RTC 则在旧动作块执行期间计算新块，并约束它与已承诺动作的衔接 [48]。一个补足状态信息，一个解决执行时序；更强的语义推理不能自动替代这两项工程。

MEM combines recent visual history with longer-term natural-language memory [47]. RTC computes a new chunk while the previous one executes and constrains continuity with committed actions [48]. One improves state information; the other coordinates execution timing. Stronger reasoning alone does not provide either.

π0.7 把语言、行为元信息和视觉子目标统一为可引导策略的输入 [16]。这使 Agent 可以说明策略或目标布局，而不必逐个关节下命令。读它的“新任务”演示时，应区分：任务没有专门示范、相关动作已经见过，以及推理时有人提供了提示或子目标。

π0.7 accepts language, behavior metadata and visual subgoals for steering [16]. An agent can specify strategy or arrangement without issuing joint commands. For novel-task demonstrations, distinguish absent task-specific demos from familiar component skills, and account for coaching or subgoals supplied at inference.

6与其他公司的技术路线比较Technical comparison with other companies

PI 的优势假设是：已有的语义知识值得保留，机器人数据负责把它落实成动作，再通过反馈提高质量。与 Generalist 的物理经验预训练相比，区别在模型起点；与 Reward 相比，区别在把多少对齐工作交给共享硬件接口；与 Dyna 相比，区别在未来视频是否成为核心训练目标。它们可以共享数据或控制方法，不能仅用 VLA、WAM 两个词划成互斥阵营。

PI’s premise is that semantic pretraining is worth preserving, robot data grounds it in action, and feedback improves execution. Against Generalist, compare initialization; against Reward, compare hardware-based alignment; against Dyna, compare future-video supervision. These choices need not form mutually exclusive camps.

推荐阅读顺序：π0 → FAST / KI → π0.5 → RECAP，再按需求读 MEM、RTC、RLT 和 π0.7。Pi API 的开放说明了部署入口 [25]；判断研究结论仍应回到各篇报告的训练范围和评测协议。

Suggested sequence: π0 → FAST / KI → π0.5 → RECAP, then MEM, RTC, RLT and π0.7 as needed. The Pi API supplies a deployment interface [25]; the reports remain the source for training and evaluation scope.
